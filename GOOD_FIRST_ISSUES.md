# Good First Issues to Open

Copy each of these into a new GitHub issue (using the templates above) in the repository listed, tagged `good-first-issue`. An empty issue tracker is currently the fastest thing making the project look inactive — this is the fastest fix for that.

## celoht-docs

1. **"Add a glossary of Web3 terms in Haitian Creole"** — USDm, gas fee, wallet, seed phrase, etc., defined in plain Kreyòl for first-time readers.
2. **"Fix broken internal links"** — audit all `.md` files for links to files that were renamed or moved.
3. **"Add a FAQ page"** — 10–15 questions a first-time visitor or partner would ask, pulled from real questions you've already answered by email/DM.

## celoht-siteweb

4. **"Add alt text to all images"** — accessibility pass, one PR per page.
5. **"Add a Haitian Creole / English language toggle to [specific page]"** — pick one page that's currently missing full Kreyòl coverage.
6. **"Fix mobile layout on [specific page]"** — describe the actual bug you've noticed on your phone.

## celoht-dapp

7. **"Add a loading state to the wallet-connect button"** — small, contained, good starter PR.
8. **"Write a testnet setup guide for contributors"** — how to get Alfajores test funds and connect Valora in dev mode.

## celoht-research

9. **"Add a template for future research briefs"** — a `TEMPLATE.md` so every new research doc follows the same structure.

## celoht-brand

10. **"Export logo in SVG + PNG at 3 standard sizes"** — if not already done, a clean, contained deliverable.

---

**Tip:** open 3–4 of these now rather than all 10 at once. A tracker with a handful of clearly-scoped, live issues reads as active; one with 10 stale, unopened ones for months reads the same as zero.
